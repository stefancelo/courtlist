# courtlist

Task management web app for Euroleague game operations staff.

**Live site:** https://stefancelo.github.io/courtlist/

## Pages
- **Home**: welcome section, latest activity feed, weather for the next host city
- **Tasks**: add, edit, delete and complete tasks; filter, sort and search
- **Analytics**: task charts and a Kanban board
- **Gameweek**: round countdown, arena checklists, fixtures linked to tasks
- **About**: app purpose, team members, testimonials
- **Contact**: contact form, office map, social links

## Tech stack
- HTML5, CSS3, Bootstrap 5.3
- Vanilla JavaScript
- localStorage for persistence
- Chart.js for charts
- Open-Meteo API for weather data
